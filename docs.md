# ai-platform 
Платформа, которая объединяет знания из разных источников (GitHub, PDF, Markdown, Notion и др.) и сокращает время поиска информации с 15 минут до 30 секунд.

### 1. Для кого предназначено
Небольшие IT-команды (5–50 человек), которым сложно искать информацию среди множества внутренних источников.

### 2. Какую задачу решает наш проект
Наша платформа предоставляет возможность координироваться в большом объеме различных источников быстро и без потери качества. У пользователя есть возможность проиндексировать нужные источники и найти нужную информацию.

### 3. Схема работы
Регистрация -> подключение источников (загрузка пдф, подключение гитхаба) -> запрос пользователя -> поиск релевантной информации -> ответ понятым языком с кратким саммари источника и ссылкой на него
